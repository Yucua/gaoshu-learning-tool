# 同济高数 · 学习工具

一个纯前端、零依赖的《高等数学》（同济大学第八版）自学工具。覆盖**上、下册全部 12 章 81 节**，把"学、练、测、复盘"闭环做到一个网页里。

> 🎓 作者是刚入学的大一新生，做这个工具最初只是为了自己学高数不挂科。如果你也在学同济高数，希望能帮到你。

## 功能

每一节都拆成"四件套"，按顺序过一遍就能吃透：

| 模块 | 说明 |
| --- | --- |
| 📖 学 | 「为什么学这个」+ 讲解（含打比方、推导链、易错点、图） |
| 🧑‍🏫 跟我做 | 老师带做例题，起手式 → 分步 → 回头看 |
| ✍️ 你自己做 | 练习题，标难度，点开看详解，做错一键进错题本 |
| ⏱️ 30 秒自查 | 先想再点开对答案 |

全书级的复盘工具：

- ❌ **错题本** —— 做错的题自动汇总，按章分组
- 🎯 **不会清单** —— 把知识点标成「半懂 / 没懂」，考前只看这一页
- 📊 **学习统计** —— 每章掌握度、窟窿一目了然
- ⚡ **考前速记** —— 没掌握的知识点 + 错题 + 公式 + 易错点，一页 A4 可打印
- 📐 **公式手册** —— 全书公式，可复制、可打印
- 📝 **章末自测** —— 随机抽题，15 分钟计时

正文里的术语（如「定积分」「洛必达」）会**自动标成可点小卡**，点一下弹出「一句话 + 打个比方 + 最小例子 + 卡住点」，还有"学到第几章才讲"的提示。

## 特色：一条硬纪律

**前章绝不用后章的知识。** 第 3 章讲洛必达，绝不会偷偷用到第 5 章才讲的定积分。

这条纪律不是嘴上说说——项目里有一个 `检查章节范围.js`，专门扫描每章内容，发现"越界用了后面的概念"就报警。全书 12 章都过了这道检查。

## 目录

完全对齐**同济八版**：

- 上册：函数与极限 / 导数与微分 / 微分中值定理与导数应用 / 不定积分 / 定积分 / 定积分的应用 / 微分方程
- 下册：向量代数与空间解析几何 / 多元函数微分法 / 重积分 / 曲线积分与曲面积分 / 无穷级数

## 技术栈

- **纯 HTML + 原生 JS**，无框架、无构建工具
- 公式渲染用 [KaTeX](https://katex.org/)（已随项目打包，`vendor/katex/`）
- 数据与渲染分离：`chapters/*.js` 是纯数据，`app.js` 是渲染引擎
- 学习进度存在 `localStorage`（不联网、不上传）

## 快速开始

**方式一：直接用单文件版（最简单）**

项目根目录下有一个已经构建好的 `高数学习工具.html`，双击就能用，不需要装任何东西、不需要联网。

**方式二：起本地服务（开发用）**

双击 `启动-高数学习工具.bat`（需要本机装了 Python），浏览器会自动打开 `http://127.0.0.1:8300/index.html`。

**方式三：手动**

```bash
python -m http.server 8300 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8300/index.html
```

## 构建与校验

需要 [Node.js](https://nodejs.org/)。有三个脚本：

```bash
# 1. 校验：把全部章节合并成单文件 高数学习工具.html
node 构建单文件版.js

# 2. 校验：检查每章是否"越界用了后面的知识"
node 检查章节范围.js
```

也可以用 npm 脚本（等价）：

```bash
npm run build     # = node 构建单文件版.js
npm run check     # = node 检查章节范围.js
```

```
├── app.js                  # 渲染引擎（UI、交互、状态）

├── 检查章节范围.js          # 「前章不用后章」检查

└── 高数学习工具.html        # 构建产物（单文件版）
```

## 如何给某章加内容

1. 新建/编辑 `chapters/chN.js`，结构参照现有章节（`window.CHAPOS.push({...})`）
2. 在 `index.html` 加一行 `<script src="chapters/chN.js"></script>`
3. 在 `构建单文件版.js` 里加对应的 `chN` 读取 + `tagChN` + 数组项
4. 跑 `node 检查章节范围.js` 确认没越界，再 `node 构建单文件版.js` 重新构建

**注意**：正文里的数学公式用 KaTeX 语法；写在 JS 字符串里时，反斜杠要写成 `\\`（如 `\\int`）。
